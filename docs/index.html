seo-check

한 페이지의 기본 SEO 신호를 터미널에서 5초 만에. 의존성 없음, Node 18 이상.
한글 제목 폭으로 잘림을 판정하고, 네이버 크롤러 Yeti 허용을 보고, canonical 이 리디렉션되는지 실제로 요청해 확인합니다.

GitHub 에서 보기 스크립트 원본

실행

curl -O https://raw.githubusercontent.com/tryoreum/seo-check/main/seo-check.mjs
node seo-check.mjs https://example.com

이런 게 나옵니다

https://example.com/

  title        예시 회사 | 서비스 소개  [폭 22]
  description  (없음)
  canonical    https://example.com  → HTTP 301 → https://example.com/
  h1           1개
  og           title ✓ · description ✗ · image ✓
  robots.txt   Googlebot 허용 · Yeti(네이버) 차단 · Bingbot 허용

  ▲ meta description 이 없습니다
  ✖ canonical 이 리디렉션됩니다 → https://example.com/
  ✖ robots.txt 가 Yeti 을 막고 있습니다

검사 항목

항목기준
title없음 · 폭 60 초과(한글 약 30자, 검색결과 잘림) · 폭 20 미만
meta description없음 · 폭 160 초과
canonical없음 · 실제 요청해 3xx 면 오류(끝 슬래시 불일치) · 404
h10개 또는 2개 이상
OG 태그og:title · og:description · og:image 누락, 상대주소
robots.txtGooglebot · Yeti · Bingbot 이 Disallow: / 로 막혔는지
기타meta robots noindex · lang · viewport · JSON-LD 유무

왜 만들었나

정적 사이트를 배포한 뒤 서치콘솔에 "리디렉션이 포함된 페이지" 가 56개 잡혔습니다. canonical 과 사이트맵에 끝 슬래시를 안 붙였고 호스팅은 슬래시 붙은 주소로 301 시키고 있었습니다. 사이트는 멀쩡히 열려서 눈으로는 못 찾는 문제였습니다. 배포 직후 한 번 돌리면 잡히는 것들을 모았습니다.

사이트 전체를 크롤해서 8개 영역 점수와 페이지별 감점 내역까지 보려면 웹 버전인 오름 무료 SEO 진단을 쓰시면 됩니다. 이 스크립트는 그중 한 페이지짜리 핵심만 떼어 온 것입니다.
